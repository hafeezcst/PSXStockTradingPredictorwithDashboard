# Portfolio Telegram Integration

## Overview
The Portfolio Management System now supports sending portfolio reports directly to Telegram! This enhancement is added to Option 6 (Export Portfolio Report) in the main menu.

## Features
- **Formatted Portfolio Reports**: Beautifully formatted messages with emojis and performance indicators
- **Real-time Performance Indicators**: Visual cues based on portfolio performance
- **Top Holdings Display**: Shows your top 5 positions with current values and P&L
- **Performance Alerts**: Smart recommendations based on portfolio status

## Setup Instructions

### Step 1: Create a Telegram Bot
1. Open Telegram and search for @BotFather
2. Send `/newbot` command
3. Follow the instructions to create your bot
4. Save the bot token provided by BotFather

### Step 2: Get Your Chat ID
1. Send a message to your bot
2. Visit: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
3. Look for the "chat" object and copy the "id" value

### Step 3: Configure Environment Variables
1. Copy `.env.example` to `.env` in the project root
2. Set your values:
   ```
   TELEGRAM_BOT_TOKEN=your_actual_bot_token
   TELEGRAM_CHAT_ID=your_actual_chat_id
   ```

## Usage
1. Run the Portfolio Management System
2. Select Option 6: "Export Portfolio Report (+ Telegram Options)"
3. The system will export files as usual
4. When prompted, type 'y' to send a report to Telegram
5. **Choose your message type:**
   - **Option 1**: Full Portfolio Report (overview + holdings + active trades)
   - **Option 2**: Active Trades Only (up to 26 signals)
6. Check your Telegram for the formatted report!

## Report Format
The Telegram message includes:
- 📊 Portfolio overview (value, cash, invested amount, return %)
- 📈 Top 5 holdings with current prices and P&L
- 🎯 **Active Trading Signals:**
  - **📈 Buy Signals**: List of all active buy signals with stock name, price, P&L%, and signal date
  - **📉 Sell Signals**: List of all active sell signals with stock name, price, P&L%, and signal date
  - Shows up to 8 signals of each type, with count if more exist
- 🚀 Performance indicators and recommendations
- 📱 Professional formatting with emojis

## Troubleshooting
- **"Telegram functionality not available"**: Install required dependencies (`pip install requests python-dotenv`)
- **"Failed to send"**: Check your bot token and chat ID configuration
- **No message received**: Ensure you've started a conversation with your bot

## Security Note
Keep your `.env` file secure and never commit it to version control. The `.env.example` file is provided as a template only.
